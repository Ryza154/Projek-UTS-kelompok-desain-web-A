DAPUR NUSANTARA — TEMA CERIA DAN BERWARNA

Susunan file:
  index.html             Halaman beranda
  profil.html            Profil usaha, visi, misi, dan nilai
  galeri.html            Galeri menu
  data.html              Tabel menu dan harga
  assets/css/style.css   Seluruh desain website
  assets/images/         Gambar hidangan dan gambar utama
  assets/fonts/          File font lokal:
    custom.woff2         Roboto Regular 400
    custom-bold.woff2    Roboto Bold 700

Cara menjalankan:
  1. Ekstrak ZIP.
  2. Jangan pindahkan file HTML atau folder assets dari tempatnya.
  3. Buka index.html menggunakan browser.
  4. Gunakan navigasi untuk berpindah halaman.

Catatan:
  - Dibuat dengan HTML5 dan CSS3, tanpa framework dan tanpa JavaScript.
  - Semua aset disimpan lokal sehingga bisa berjalan offline.
  - Tampilan responsif untuk desktop, tablet, dan ponsel.
  - Folder font disediakan sesuai struktur proyek. CSS tidak diubah agar tampilan website tetap sama.
  - Menu dan harga merupakan data contoh untuk tugas desain web.
